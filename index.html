Planet Insights Platform Web Map Helper

This application aims to help users of Planet Insights Platform to create web map applications. If you have an Insights Platform account you can paste in a configuration id and the app will return a preview web map, the center & zoom, and an XYZ url template. The XYZ url is often the easiest way to make a web map, but the Insights Platform doesn't (yet) make it easy to figure out what it should be. There is also an experimental feature to generate prompts for AI tools to generate code to make web maps.

You can find the ID for your configuration on the configurations page. Just copy the ID and paste it in below. The ID should look like 'd410e654-397f-4734-a1dc-f3abe3e5bae5'
