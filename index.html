Planet Insights Platform Web Map Helper

This application aims to help users of Planet Insights Platform to create web map applications. If you have an Insights Platform account you can paste in a configuration id and the app will return a preview web map, the center & zoom, and an XYZ url template. The XYZ url is often the easiest way to make a web map, but the Insights Platform doesn't (yet) make it easy to figure out what it should be. There is also an experimental feature to generate prompts for AI tools to generate code to make web maps.

You can find the ID for your configuration on the configurations page. Just copy the ID and paste it in below. The ID should look like 'd410e654-397f-4734-a1dc-f3abe3e5bae5'

AI Code Generation Prompt Builder

This tool provides a starting point to prompt AI coding tools to create web map applications with your selected layer, properly centered and zoomed in. Just select what options you want for your map library, basemap and controls and then copy the text box and paste it into the chat window of your preferred tool.

Most good AI coding tools will likely generate a working map for you, and guide you on how to use it and publish it. It's been tested with ChatGPT (mostly 4o) and Cursor (mostly Claude 3.5), but other tools should work too. If it doesn't give you a working map the first time then try a more powerful model (ie o3, Claude 3.7/4 in Thinking mode, gemini 2.5 pro MAX, etc).

Feel free to customize the prompt before adding it in, though it's usually better to first get something working and then iterate with smaller additions. View this as a jumping off point - after the map is working you can then add more features and customize it to your needs.
