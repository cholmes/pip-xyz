# pip-xyz

An application to get XYZ template urls from Planet Insights Platform and assist with creation of web maps. 

## Usage

Easiest way to make use of this is to go to https://cholmes.github.io/pip-xyz. There you can enter a configuration
id from Planet Insights Platform. That will give you a list of layers, and if you select one then the app will show
a map of it, the center & zoom, and an area to generate AI coding prompts.
